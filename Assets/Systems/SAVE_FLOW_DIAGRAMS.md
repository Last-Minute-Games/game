## Data Flow Architecture

```
????????????????????????????????????????????????????????????????
?                    SAVE DATA FLOW                            ?
????????????????????????????????????????????????????????????????

Game State
    ?
    ??? GameFlags (all flags in memory)
    ?       ?
    ?       ??? day.one, day.two, character.marco, etc.
    ?
    ??? ClockTimer (time remaining)
    ?       ?
    ?       ??? timeLeft = 50.5 seconds
    ?
    ??? GameFlagsManager (current save name)
            ?
            ??? "Jess"

                    ? SAVE ?

Application.persistentDataPath/Saves/GameFlags_Jess.json
    ?
    ??? {
          "flags": ["day.two", "character.marco", ...],
          "clockTimeLeft": 50.5,
          "currentDay": "day.two"
        }

                    ? LOAD ?

Game State Restored
    ?
    ??? GameFlags.LoadFromFile("Jess")
    ?       ?
    ?       ??? All flags restored to _activeFlags
    ?
    ??? ClockTimer.RestoreTimeLeft(50.5)
    ?       ?
    ?       ??? timeLeft = 50.5
    ?
    ??? Continue playing from saved state
```

    ?
    ??? SaveToFile(saveName)
    ?       ?

    ?       ??? Serialize to JSON
    ?       ??? Write to disk

            ?
            ??? Read from disk
            ??? Deserialize JSON
            ??? Restore all flags
            ??? ClockTimer.RestoreTimeLeft(value)

## Error Handling Flow

```
??????????????????????????????????????????????????????????????
?                    ERROR SCENARIOS                         ?
??????????????????????????????????????????????????????????????

SaveNamePrompt
    ?
    ??? Name too short (< 3 chars)
    ?       ??? Show error: "Name must be at least 3 characters"
    ?
    ??? Name too long (> 16 chars)
    ?       ??? Show error: "Name must be 16 characters or less"
    ?
    ??? Name already exists
    ?       ??? Show error: "A save with this name already exists"
    ?
    ??? Invalid characters
            ??? Unity's TMP_InputField can restrict this

LoadGameUI
    ?
    ??? No saves exist
    ?       ??? Show: "No saved games found"
    ?
    ??? Save file corrupted
    ?       ??? Skip the corrupted save, log error
    ?
    ??? Save directory missing
            ??? Create directory automatically

GameFlags.LoadFromFile()
    ?
    ??? File doesn't exist
    ?       ??? Return false, use defaults
    ?
    ??? JSON deserialization fails
    ?       ??? Log error, return false
    ?
    ??? ClockTimer not found
            ??? Skip time restoration, continue with defaults
```

## Quick Reference Commands

### Check if any saves exist:
```csharp
string saveDirectory = Path.Combine(Application.persistentDataPath, "Saves");
string[] saveFiles = Directory.GetFiles(saveDirectory, "GameFlags_*.json");
bool hasSaves = saveFiles.Length > 0;
```

### Get save metadata:
```csharp
GameFlagsSaveData data = GameFlags.GetSaveMetadata("Jess");
if (data != null)
{
    Debug.Log($"Day: {data.currentDay}, Time: {data.clockTimeLeft}");
}
```

### Create new save:
```csharp
bool success = GameFlagsManager.CreateNewSave("PlayerName");
```

### Load existing save:
```csharp
GameFlagsManager.SetCurrentSaveName("PlayerName");
bool success = GameFlagsManager.LoadCurrentGame();
```

### Delete save:
```csharp
bool success = GameFlags.DeleteSaveFile("PlayerName");
```
