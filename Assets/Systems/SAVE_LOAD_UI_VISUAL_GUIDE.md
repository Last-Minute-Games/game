## Size Reference

### SaveNamePromptPanel:
- **Full overlay:** Screen size
- **Container:** 400 x 250 pixels
- **Input Field:** 350 x 50 pixels
- **Buttons:** 150 x 50 pixels each

### LoadGameUIPanel:
- **Full overlay:** Screen size
- **Container:** 600 x 500 pixels
- **Scroll View:** 550 x 350 pixels
- **Save Slot:** 520 x 80 pixels each
- **Back Button:** 150 x 50 pixels

### PlayChoicePanel:
- **Full overlay:** Screen size
- **Container:** 400 x 300 pixels
- **Buttons:** 300 x 50 pixels each

## Color Palette (Medieval Theme)

### Panels/Backgrounds:
```
Dark Overlay:       #000000 (Alpha: 200/255 = 78%)
Container:          #3E2723 (Dark Brown)
                or  #F5E6D3 (Parchment)
```

### Text:
```
Title Text:         #FFF8E1 (Cream)
Body Text:          #FFFFFF (White)
                or  #3E2723 (Dark Brown)
Error Text:         #FF4444 (Red)
Gray Text:          #888888 (Gray)
```

### Buttons:
```
Normal:             #D7CCC8 (Cream/Tan)
Highlighted:        #FFF8E1 (Lighter Cream)
Pressed:            #8D6E63 (Darker Brown)
Delete Button:      #8B0000 (Dark Red)
```

## Font Sizes

```
Title (Welcome Back, Load Game):    36-40pt
Section Headers:                     32-36pt
Save Name (in slots):                24pt (Bold)
Body Text:                           20-24pt
Small Info (Day, Time):              20pt
Button Text:                         24pt
Error Messages:                      18pt
```

---

## Spacing

```
Between UI elements:     10-20 pixels
Panel padding:          20-30 pixels
Save slot spacing:      10 pixels
Button spacing:         20 pixels
```

---

## Z-Order (Layering)

From back to front:
1. Main Menu (Play, Settings, etc.)
2. PlayChoicePanel
3. SaveNamePromptPanel
4. LoadGameUIPanel
5. DeleteConfirmPanel (inside LoadGameUI)

All panels should have a semi-transparent dark overlay to dim what's behind them.

---

## Animation

All panels fade in/out:
- **Duration:** 0.3-0.5 seconds
- **Easing:** Smooth lerp
- **Alpha:** 0 ? 1 (fade in), 1 ? 0 (fade out)
- **Interactable:** Enabled after fade in completes

---

## Matching Your Game Style

Based on your "Castle of Time" main menu:
- Use the same decorative font for titles
- Match button styling (the cream/tan buttons you have)
- Use consistent spacing
- Keep the medieval/gothic aesthetic
- Consider adding subtle texture to panels (parchment, stone, etc.)
